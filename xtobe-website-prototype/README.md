# XTOBE website prototype

This is a local, private Next.js + TypeScript prototype intended for internal review only. Do not publish or deploy without final approval.

Run locally:

1. cd xtobe-website-prototype
2. npm install
3. npm run dev

Notes:
- This prototype uses the local public/xtobe-hero-v2.svg as the cinematic hero.
- Keep the prototype private and use it for design and technical review only.
